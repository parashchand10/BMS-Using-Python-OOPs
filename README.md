# BMS-Using-Python-OOPs
A simple Bank Management System built using Python Object-Oriented Programming (OOP) concepts. This project demonstrates core OOP principles such as classes, inheritance, encapsulation, and data abstraction through real-world banking operations.

### Features

1. Create bank accounts
2. View account details
3. Check account balance
4. Deposit money
5. Withdraw money
Transfer money between accounts

Demonstrates encapsulation using private attributes and methods

### OOP Concepts Used

1. Class & Object – Represents bank and account holders
2. Inheritance – Account holder inherits common bank details
3. Encapsulation – Sensitive data protected using private variables (__balance, __account_number)
4. Abstraction – Operations exposed through methods only

### Technologies Used

1. Language: Python 3
2. Environment: Jupyter Notebook / VS Code
3. Concepts: OOP, Loops, Conditional Statements, Lists
